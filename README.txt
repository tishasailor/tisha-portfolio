TISHA'S IT PORTFOLIO — QUICK START
===================================

-----
index.html  Main page and portfolio content

HOW TO OPEN IT
--------------
1. Download and extract the ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. In VS Code, right-click index.html and choose "Open with Live Server"
   if you have the Live Server extension installed.
   OR double-click index.html to open it in your browser.
4. Edit the placeholders before publishing.

PERSONAL DETAILS TO UPDATE
--------------------------
1. In index.html, check the name "Tisha" and course title.
2. Replace [Add your college/university] and [Add year] with accurate details.
3. Replace your.email@example.com with your real professional email.
4. Replace the GitHub and LinkedIn homepage links with your own profile URLs.
5. Add a real profile photo if you want one. The current circle is a designed
   placeholder, not a real photo.
6. Add real screenshots of your projects. The project visuals are illustrative
   CSS mockups, not screenshots of the actual working applications.
7. Add actual GitHub repository URLs only after confirming the repositories
   are public and ready to share.
8. Review the skills list and remove anything you have not used yet.

PUBLISHING WITH GITHUB PAGES
----------------------------
This is a static HTML/CSS/JavaScript site, so it can be published with GitHub Pages.

1. Create a GitHub repository, for example: tisha-portfolio.
2. Upload index.html, style.css, and script.js to the repository root.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose "Deploy from a branch".
5. Select the main branch and /(root), then save.
6. Wait for the published URL to appear on the Pages settings screen.

IMPORTANT
---------
GitHub Pages does not run PHP. Sanskriti Elegance can be showcased here with
a description, screenshots, and a source-code link, but the PHP/MySQL app
itself needs a PHP-capable hosting environment to run online.

The contact section currently links to sample destinations until you update them.
Do not publish private contact information you do not want to share publicly.
